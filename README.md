# 魔塔 Remastered

基于经典魔塔 [xhy1999/MagicTower](https://github.com/xhy1999/MagicTower) 重制的手机魔塔。核心开发原则：**忠于原版**——原版是被大量玩家验证的成熟设计，任何增强与修正都先比对原版、确认不偏离核心玩法后再落地。

- 主版本目录：`data.js`（关卡/怪物/道具/NPC/商店数据）+ `game.js`（引擎与事件逻辑）+ `index.html`（入口与样式）
- 本地运行端口：8001
- 当前版本：**v1.2.0**

---

## 一、版本号规则

采用 **SemVer 适配版 `vMAJOR.MINOR.PATCH`**，三类变更界限如下：

| 位 | 语义 | 触发条件 | 本项目实例 |
|---|---|---|---|
| **MAJOR（主版本）** | 重大改写 | 背离"忠于原版"原则的核心玩法/架构重构 | 目前未发生（保留为红线） |
| **MINOR（次版本）** | 新增内容 | 新增机制 / 新系统 / 新结局 | 四结局、圣水机制、双灵杖路线、终局 boss 原版数值对齐 |
| **PATCH（修订号）** | 修正 | bug 修复 / 数值微调 / 原版还原 | 仙子挡路、商店漏移植、NPC 灰透明挡路 |

**打包产物命名**：`magic-tower-remastered-<描述>-YYYYMMDD.zip`（日期后缀仅作人工辨识，不计入版本号）。每次发版：bump 对应位 → 在「版本更新日志」追加一条 → 重新打包三件套。

## 三、与原版的关键设计约定

| 设计点 | 说明 |
|---|---|
| **终局 boss** | 血影 / 魔龙：**一个 boss、一条血、占 9 格、只打一次**。中心格 `_8` 定胜负，外围 8 格为身体占位（原版同此行为，非 bug）。 |
| **双灵杖路线** | 交灵杖 → 血影（`monster11_8`）；不交 → 魔龙（`monster12_8`）。冰杖不参与 boss 替代关系。 |
| **圣水** | `item06_3`，生命/攻击/防御 ×150%，入背包后**主动点击使用**。 |
| **进魔界强化** | 玩家三围 ×1.3（纯系数，忠于原版，无金币/经验保底）。 |
| **商店守门形象** | `shop01_1/01_3/02_1/02_3` 点击无反应（原版 `canBuy=false`）；增益在中间柜台 `shop01_2`（800血/4攻/4防）、`shop02_2`（4000血/20攻/20防）。 |
| **道具命名** | 仅破墙工具 `item09_7` 由"稿子"改为"镐"（确认保留）；`item09_8` "星光神锒"为原版本名（非错别字）；其余道具名与原版一致。 |
| **怪物图鉴解锁** | 原版为特殊地图拾取"圣光徽"（`item09_6`）后按 D 键查看怪物信息；重制版按用户指定改为 1 层左下角老者对话赠《怪物图鉴》，解锁图鉴查看 + 显伤（初始不自动拥有）。 |
| **幸运金币** | 原版为"幸运硬币"，一次性 +300 金币、无双倍；重制版自定义为"幸运金币"：拾取 +100 金币，此后战斗金币 1.5 倍。 |
| **四结局** | 在原始单结局之外新增分支结局（`end1` 等），主线"忠于原版"路径不受影响。 |

## 五、构建与运行

```bash
# 本地静态托管（开发预览）
cd magic-tower-remastered
python3 -m http.server 8001
# 浏览器打开 http://localhost:8001
```

- **发布包清单**：`data.js` / `game.js` / `index.html`（三件套，无构建步骤）。
- **打包命令**：`zip -9 magic-tower-remastered-<描述>-YYYYMMDD.zip data.js game.js index.html`
- **部署说明**：本仓库为静态前端，可直接托管于任意静态服务器 / GitHub Pages。注意 `zip` 默认保留源文件真实编辑时间（非打包时间），属正常行为。
